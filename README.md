## Sobre o projeto

**AXIS Present** é uma aplicação Web desenvolvida para criação, edição e organização de apresentações.

A proposta do projeto é construir uma experiência inspirada em ferramentas tradicionais de apresentação, utilizando tecnologias fundamentais da Web para criar uma interface própria.

O projeto trabalha principalmente a integração entre:

```text
HTML
  ↓
Estrutura

CSS
  ↓
Interface

JavaScript
  ↓
Interação

      ↓

AXIS Present
